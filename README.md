# Election-Polls-Scraper-Philippines-Poland
Web scraping (BeautifulSoup) et traitement (pandas) de données de sondages électoraux pour 10 élections (Philippines, Pologne). Nettoyage, restructuration large-long, attribution de l'orientation politique des candidats, détection d'outliers (score Z) et tableau de bord interactif Streamlit pour visualiser l'évolution des prédictions.
